# dispatch-code-review

Compatibility alias for dispatch code review. Requires sibling [dispatch](../dispatch/README.md).

Invoke `/dispatch-code-review [level] [(pins)] argument`. It maps to `/dispatch review code:`; see [dispatch usage](../dispatch/README.md) for Node prerequisites, configuration, and recovery. The branch contract is [SKILL.md](SKILL.md).

Reuses or authors the governing spec before review; the removed `--context` option is not an intent channel. Standalone code review adds no authoring approval gate. See [review](../dispatch/references/readme/review.md).
