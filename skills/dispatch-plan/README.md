# dispatch-plan

Compatibility alias for dispatch planning. Requires sibling [dispatch](../dispatch/README.md).

Invoke `/dispatch-plan [level] [(pins)] argument`. It maps to `start plan`; see [dispatch usage](../dispatch/README.md) for Node prerequisites, configuration, and recovery. The branch contract is [SKILL.md](.).

Uses the same governing spec settlement, applicable spec approval and layered plan workflow as Dispatch. See [planning](../dispatch/references/readme/plan.md).
