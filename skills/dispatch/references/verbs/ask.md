# Ask

Use `start ask --session-dir <dir> --orchestrator <platform> -- <question>`; unprefixed invocation text maps here. `--provider P` pins one configured provider. The driver prepares bounded prompts and returns sanitized raw claims with source identities. Inspect the independent claims and report their evidence; follow [the contract](../..) for native captures and recovery.

Final claims are previews. Before synthesis, read the full files listed in `captures` when a preview omits supporting evidence, caveats, or context needed to resolve disagreement. If a needed capture is unavailable, report that evidence gap and bound the conclusion to the available claims.
