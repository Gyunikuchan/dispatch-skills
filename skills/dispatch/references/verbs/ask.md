# Ask

Use `start ask --session-dir <dir> --orchestrator <platform> -- <question>`; unprefixed invocation text maps here. `--provider P` pins one configured provider. The driver prepares bounded prompts and returns sanitized raw claims with source identities. Inspect independent claims, adjudicate disagreements against source captures, and report a synthesized evidence-backed verdict as executive deputy. Follow [the contract](../..) for native captures and recovery.

Before delegation, when the answer depends on settled chat decisions or constraints absent from supplied files, include a concise summary in the question or supplied files. Include only settled facts needed to answer the question.

Final claims are previews. Before synthesis, read the full files listed in `captures` when a preview omits supporting evidence, caveats, or context needed to resolve disagreement. If a needed capture is unavailable, report that evidence gap and bound the conclusion to the available claims.
