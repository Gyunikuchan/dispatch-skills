# Verbs

| Verb | Result |
|---|---|
| ask | Independent claims |
| design | Reviewed, approved design |
| plan | Reviewed implementation plan |
| review | Verified findings; fixes when requested |
| implement | Bounded changes, criterion evidence, walkthrough |

Invoke `/dispatch [level] [(pins)] [verb:] argument`; omitted verb means ask. Start examples and prerequisites are in [usage](../../README.md). Review defaults to report-only; design ends at approval, then a separate implementation invocation delivers its increments.
